# E 题可行性评审与第一阶段实施说明

## 结论先行

原方案的研究方向可行，但按原样直接实施的可行性为 **6/10**。它正确识别了无标签目标域、跨设备与转速失配、以及按窗口随机划分会泄漏等关键问题；但把两视图 DANN + LMMD 直接设为主方案过于激进。目标域只有 16 条相关性很强的长序列，LMMD 依赖的伪标签缺乏独立验证，不能作为首个可以信赖的结论来源。

本仓库已落地保守 MVP：受控源域、原始文件分组验证、相对转频特征、source-only 与 CORAL 两个可比较输出，以及目标域 OOD/复核标记。它完成了可复现的诊断流程，不声称已经证明目标域诊断正确。

## 已核对的实施事实

- 受控源域确有 16 个文件：N、OR、IR、B 各 4 个。4 条正常样本在 `48kHz_Normal_data`，其余故障样本在 `48kHz_DE_data`；不能仅按后一个目录筛选，否则会错误得到 12 条全故障数据。
- 源信号中存在唯一的 `_DE_time` / `_FE_time` 变量；RPM 优先从变量读取，缺失时仅对文件名已编码转速的正常样本解析。
- A-P 均为一个同名、`256000 x 1` 的变量；MVP 将其视为无标签目标文件，使用题设名义转速 600 rpm，只用于相对转频（order）特征。
- 源 48 kHz 信号先以 `resample_poly(x, 2, 3)` 抗混叠重采样到 32 kHz；目标信号保持 32 kHz。

## 运行结果及其含义

默认 DE 受控源域的四折文件分组验证得到 Macro-F1 = 1.000、Balanced Accuracy = 1.000；每一折严格留出每个类别的一整个原始文件。以 FE 替代 DE 时，相同流程得到 Macro-F1 = 0.818、Balanced Accuracy = 0.813。这支持“在该受控 CWRU 子集内，DE 更易区分类别”，但**不证明** DE 与列车传感器更相似，也不证明能迁移成功。

目标域的实际诊断信号更重要：source-only 分类器将 A-P 全部偏向 N，且 16/16 文件均超过源域 99% Mahalanobis 距离阈值；CORAL 给出的候选类别与 source-only 在 9/16 文件上不一致。因此所有 A-P 条目均被标记 `final_review_required=True`。这个结果是强域偏移证据，而不是“目标域全正常”或 CORAL 标签正确的证据。

加入轻量特征级 DANN 后，严格源文件留出的 Macro-F1 仍为 1.000，但目标候选对训练轮数敏感：同一随机种子下，12 轮与 50 轮的 A-P 候选仅 7/16 一致。训练末期域判别准确率约为 0.45，说明对抗项在改变表示，但这既不证明类别条件已对齐，也不证明任一目标标签正确。三方法汇总表因此仍将 16/16 文件标为复核。

## 最严重技术风险

1. **跨域标签不可验证。** 无目标真值时，目标概率、聚类、t-SNE/UMAP、MMD 降低和伪标签一致率都不能变成目标准确率。
2. **受控源域有故障尺寸混杂。** 16 文件设计适合作为可解释起点，却只使用 007 mil 内圈/滚动体和 6 o'clock、007 mil 外圈；高源域分数可能部分识别了特定损伤尺度或台架工况，而非可泛化故障机理。
3. **同一时间窗不等于同一转数。** 0.512 s 在目标约为 5.12 转、在约 1750 rpm 源域约为 14.9 转。直接把等时间波形输入 CNN 会混入转速差；MVP 通过相对转频频带减轻，而非消除该问题。
4. **DANN + LMMD 的循环风险。** DANN 可把错误类别混合；LMMD 再依据高置信伪标签进行类别条件对齐，会放大初期偏差。16 条目标长序列不提供足够独立样本来验证这一链条。
5. **窗口数不是独立样本数。** 50% 重叠窗口之间强相关。它们可帮助文件内稳健汇总，不能当作独立训练/测试记录，也不能把窗口准确率当作文件级泛化能力。

## 必须修改项

1. **把文件作为分割、统计和报告单位。** 保持现有 MVP 的规则：一个 `.mat` 的所有窗口只在一个折内；源域报告文件级 Macro-F1、Balanced Accuracy、各类 Recall 与每折文件清单。
2. **把 source-only、CORAL、DANN 分开报告。** 主表必须给出方法间 A-P 一致/不一致和复核标记；不得挑选某一种输出后称为真值。现阶段 source-only 与 CORAL 已实现，DANN 只能在此基线之后加入。
3. **按阶次表达并进行灵敏度分析。** 以频率除以转频构成相对阶次特征；比较约 5、10、15 转覆盖下的结论。若要使用等转数 1D 波形，必须明确名义转速近似和目标瞬时转速未知的限制，不能暗称精确阶次跟踪。
4. **扩展源域时做文件级消融。** 将 16 文件仅作为受控起点；扩展 48 kHz DE 时，按原始文件、载荷和故障尺寸记录采样/类别权重。任何扩展后的结果都要与受控版本并列，不能混在一起。
5. **对目标输出设拒识。** 概率低、窗口意见分散、模型间不一致或 OOD 时标为“需复核”。竞赛要求分类时可交付候选类，但论文必须说明它是模型候选而不是真实标签。

## 建议保留的创新点

- 源域机理频率用于验证 CWRU 特征，而非给未知目标轴承峰值强行命名。
- 以“源/目标相对阶次结构是否相似”代替绝对频率对齐。
- 把域距离、方法一致性和文件内稳定性合并为可信度证据链，而非单一 softmax 概率。
- 事前机理解释、迁移过程诊断、事后特征归因的三段式解释框架。

## 当前 MVP 的使用方法

```powershell
python .\src\bearing_mvp.py
```

输出在 `outputs\mvp\`：

- `source_file_cv_predictions.csv`：严格文件级交叉验证；
- `target_predictions_source_only.csv`：不适应目标域的参考输出及 OOD 诊断；
- `target_predictions_coral.csv`：仅利用无标签目标协方差的 CORAL 候选输出；
- `target_prediction_comparison.csv`：两方法是否一致及最终复核状态；
- `data_manifest.csv`：精确文件清单和窗口数；
- `summary.json`：方法、特征与源域指标。

可选 DANN 运行后，`outputs\\dann\\three_method_comparison.csv` 将汇总
source-only、CORAL 和 DANN；任一方法 OOD、低稳定性或类别分歧都会保留最终复核标记。

## 增强版顺序

1. 先完成 16 文件受控源域和扩展源域的稳健性对照；
2. 加入 MMD/A-distance、UMAP 与文件级稳定性图，但只作域差异诊断；
3. 实现特征级 CORAL 的超参数/窗口长度消融；
4. 轻量特征级 DANN 已作为可选、MIT 来源可追溯的基线加入；LMMD 仍应是后续消融项，且必须以 source-only、CORAL、DANN 三者均已可复现为前提；
5. 仅在模型间结论稳定、OOD 降低且机理特征相容时，给出带“候选/需复核”措辞的 A-P 分类表。

## 论文绝对不能写的结论

- “A-P 目标域准确率为 X%”；
- “聚类纯度、伪标签一致率或 MMD 降低证明目标诊断正确”；
- “目标某谱峰就是 BPFO/BPFI/BSF”；
- “滑窗后类别平衡”取代原始文件层面的类别不平衡说明；
- “DE 一定最适合列车目标域”，或“本实验已经证明跨设备泛化成功”。
