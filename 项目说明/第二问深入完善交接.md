## 主要结论

- Diagnostic26 MLP：五种子 LOLO Macro-F1 `0.923 ± 0.018`，BA `0.935 ± 0.016`。每 seed 先平均四载荷折，再算种子间均值和样本标准差。
- RF Macro-F1 `0.916 ± 0.016`。MLP 在五个 seed 中仅三个优于 RF；MLP−LR 和 MLP−RF 的配对 bootstrap 区间均包含零。推荐 MLP 为当前均值领先主模型，保留 RF 强基线，不能宣称显著优于。
- 四模型的五个 seed 均以 0 hp 为最弱载荷。MLP 的 0 hp 平均 Macro-F1 为 `0.796`，IR Recall 为 `0.400`。
- MLP 的 `IR014_0`、`OR014@6_0`、`OR014@6_3` 五 seed 均错误，`IR021_0` 四 seed 错误。前两个 0 hp 文件接近其他类别中心；IR021_0 仍接近 IR 中心，不能用统一物理根因解释。
- 各载荷类别、尺寸和外圈位置计数完全相同。数据不支持用这些计数失衡解释 0 hp；特征漂移与类边界重叠只有关联性证据。
- 温度校准没有稳定改善：平均 NLL、Brier、ECE 均上升，五 seed 中没有一个同时改善 NLL/ECE。因此导出模型默认不应用温度；可再生的逐样本校准缓存未随封版保留。
- 去幅值、去包络、去阶次后的 MLP 平均 F1 分别约 `0.890`、`0.891`、`0.897`。这是源域消融证据，不代表保留幅值一定更利于目标域迁移。

## 实施中的必要修正

1. 原基线 448 条预测及概率完全复现后，才进行增强。新结果不覆盖旧基线。
2. 传统模型的 `random_state` 随 seed 改变；MLP 两个候选参数共用验证折及初始化种子。
3. 内层在唯一文件行上执行分层划分，通常三折；保证 N 类进入每折。校准更深层仅两个 N 文件时使用两折。与原版 SGKF 启发式划分存在协议差别，不能把两版指标差全归因于种子。
4. SVM 内层评分与外层预测都采用概率最大值，避免 `predict` 与 `predict_proba` 的决策差异。
5. 校准集的每条 OOF 概率都由不含该文件的训练、调参及早停流程生成；温度应用于文件平均概率的对数。保存训练/验证 file_id 清单，可审计。

## 后续必须避免的错误

- 56 MAT 文件是统计单位，806 窗口和五 seed 的重复预测不能扩充独立样本数。文件 bootstrap 区间条件于已有预测，不覆盖重训或所有未见载荷的不确定性。
- 四折 F1 的均值与 56 文件合并的 pooled F1 不是同一指标；区分 fold SD 与 seed SD。原 Group CV 只复现旧协议，本轮未额外做完善版多种子 Group CV。
- A–P 未用于任何本轮训练、调参、校准、选模或评价；没有 A–P 真值，不报告目标准确率。目标几何未知，不擅自标注目标 BPFO/BPFI/BSF。
- 第一问 Diagnostic26 用过全源域方差/相关性筛选，MI 仅作审计。因此只能宣称固定输入 schema 下第二问的训练/验证隔离，不能宣称包括第一问筛选在内的端到端完全独立。Transfer20 是预先固定名单。若以后要求端到端验证，需单独规划，而非悄悄更改第一问。
- N 类只有四文件。全判对不意味着总体 Recall 必为一；尺寸/位置/试验关联限制因果解释。源域概率可靠性不能直接外推至目标域。
- 原始数据和第一问输入不做迎合指标的删除、滤波、改标签或改窗口。旧实验目录 `outputs/mvp*`、`outputs/dann*` 不代表当前正式迁移结果。
