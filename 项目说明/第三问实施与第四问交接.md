# 第三问实施与第四问交接

更新日期：2026-09-05。第三问 CORAL 已按方法检查意见修订、重跑并封版；正式结果在 `outputs/q3/`。

## 固定边界与本轮修复

- 仅使用冻结的 Transfer20 与 Q2 Transfer20 接口；目标 A–P 一旦出现 `label` 列即拒绝运行。目标标签未用于拟合、损失、参数选择、模型选择或评价。
- CORAL 改为窗口级 embedding 的**文件等权**均值与协方差：每个源/目标 MAT 文件总权重相同，未将 32D embedding 简化为仅 56/16 个文件均值。
- CORAL Logistic Regression 设为 `class_weight=None`，仅以类/文件均衡 sample weight 加权一次。
- 新增公平的 Source-linear：与 CORAL 共用冻结 encoder、线性头与 sample weight，唯一差异为不进行协方差对齐。
- 最终表直接从 CORAL 文件级概率表构造；概率、置信度、窗口一致性、熵、margin 和子采样不再混用 DANN 字段。

CORAL A–P 分布为 N=`0`、B=`4`、IR=`4`、OR=`8`，未触发单类超过 75% 的塌缩警告；该分布不是正确性证据，也没有被用作任何约束。DANN 的 mean-probability 为 OR=`15/16`、majority-vote 为 OR=`13/16`，仍只作为失败对照。
